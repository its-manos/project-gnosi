# World-history photo and historical-image credits

Twenty image covers replace the generic editorial artwork for the world-history path. Fifteen additional source assets are bundled; five existing licensed assets are reused without duplicating their bytes. Existing inline diagrams remain unchanged. All source files are retained without destructive crops; the app may crop cover thumbnails, while the zoom viewer shows the complete frame.

Only the cover discriminator, cover URL, caption, creator credit and credit URL change. Learning text, research sources, quizzes, question slots, IDs, path order and progress rules stay unchanged. No dependencies, migrations, native configuration or launcher assets change.

The newly retrieved photographs and document reproductions are public domain or CC BY/CC BY-SA. Each resized JPEG retains the source licence. File-description metadata and exact licence links are recorded in `scripts/fixtures/world-history-photo-rights.json`; source links and credits also appear in the app. Share-alike terms apply to the relevant image derivatives, not unrelated app code. Reuse does not imply institutional endorsement. No generative image editing was used.

Images are selected as evidence or context, not historical reconstructions. The farming photograph is labelled modern; the Stromatolite photograph depicts present-day structures; the 1507 map is a historical representation; the manuscript image depicts Mongol archers in a later manuscript. The latter file name contains “1305”, but the source description dates the pictured manuscript to approximately 1430–1434, which is the date used in the caption. The real disassembled phone does not make the article’s hypothetical supply-chain scenario into researched company data.
